## 2. 요구사항 핵심 요소 분석

| 항목 | 핵심 분석 내용 | 구현 타겟 모듈 |
| :--- | :--- | :--- |
| **Base Path** | 기본 URL prefix를 `DEFAULT_PREFIX` (기본값 `/votes`)로 관리하며, 모든 관리자 및 사용자 라우트의 베이스로 작동 | `core/config.py`, `main.py` |
| **이벤트 관리** | 이벤트 생성 시 이름(slug, 예: `BaazarEvent`), 제목, 소개 설명, 대표 소개 이미지 등록 및 수정/삭제 | `routers/admin_router.py`, `services/event_service.py` |
| **Subpath 접근** | `/votes/BaazarEvent`와 같이 이벤트 식별자로 직접 접속하는 랜딩 UX 제공 | `routers/event_view_router.py` |
| **하위 항목 등록** | 참여자가 자율적으로 제목, 설명, 이미지를 업로드하며 핀번호(PIN)를 필수 지정 | `routers/item_router.py`, `services/item_service.py` |
| **핀번호 권한** | 등록 시 지정한 핀번호와 일치하는 경우에만 수정/삭제 허용 (비밀번호 단방향 암호화) | `core/security.py` |
| **듀얼 뷰 & 투표** | 간략보기(썸네일, 제목, 요약 텍스트)에서 즉각 투표, 자세히보기(모달)에서 상세 정보 및 관리 기능 제공 | `templates/event/detail.html`, `static/js/vote.js` |
| **이미지 최적화** | 원본 이미지 폭이 1920px을 초과할 경우 비율 유지 1920px로 리사이징 및 압축 변환 | `services/image_service.py` |
