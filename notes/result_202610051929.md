## 3. 핵심 구현 상세

### 3.1 Keycloak 세션 검증 파이프라인 (`app/core/auth.py`)
- **엔드포인트**: `GET {AUTH_URL}/api/verify-session?require_role=manager`
- **검증 흐름**:
  1. 클라이언트의 `auth_session` 쿠키를 추출.
  2. 세션이 없을 경우 즉시 `is_manager=False` 반환.
  3. 프록시 호출을 통해 `is_manager == True` 또는 `role_flag in ("1", "2")` 또는 roles에 manager/super 포함 여부 판별.
  4. 외부 네트워크 지연/오류 시 장애 격리 및 graceful 비인가 처리.

### 3.2 303 See Other 로그인 바운스 매커니즘
- 비로그인 또는 일반 사용자가 관리자 전용 URL(`/votes/create`, `/votes/edit/{id}`, `/votes/delete/{id}`)에 접근하면 `AdminAuthRedirectException`이 발생하며 `main.py`의 핸들러에 의해 다음과 같이 바운스됩니다:
  ```text
  303 See Other
  Location: https://holyseeds.thewayworks.net/auth/login?error=관리자(Manager)+권한이+필요한+페이지입니다.&redirect=...&require_role=manager
  ```

### 3.3 UI / UX 상태 분기
- **관리자(`is_manager=True`)**:
  - 네비게이션에 `[Manager]` 녹색 뱃지와 사용자 이름, 로그아웃 버튼 노출.
  - "새 이벤트 개설하기", "수정", "삭제" 버튼 정상 작동.
- **일반 회원 / 비로그인**:
  - 대시보드 상단에 일반 방문자 안내 배너 표시.
  - "새 이벤트 개설", "수정", "삭제" 버튼에 자물쇠 아이콘 표시 및 클릭 시 로그인 페이지로 안전하게 유도.
