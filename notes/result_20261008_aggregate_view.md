# 참여 이벤트 전체 등록 항목 "한눈에 모아보기" 기능 구현 결과 보고서

## 1. 개요 및 요구사항 반영 내역

투표 참여형 이벤트 상세 페이지에서 수많은 참여 항목(작품, 포스터, 비디오 등)을 한눈에 조망할 수 있는 **"모아보기"** 기능을 구현하였습니다.

### 요구사항 구현 체크리스트
- [x] **모아보기 버튼 제공**:
  - 이벤트 히어로 배너 CTA 영역에 `[한눈에 모아보기]` 버튼 제공
  - 참여 작품 갤러리 섹션 헤더에 `[일반 카드뷰] / [모아보기]` 모드 전환 토글 탭 제공
  - 갤러리 섹션 헤더에 `[전체화면 모아보기]` 버튼 제공
- [x] **개별 카드 구성요소**:
  - 텍스트, 설명, 불필요한 마진 없이 **대표이미지 또는 대표영상만 100% 꽉 채워 노출** (`object-cover`)
  - 비디오의 경우 좌측 상단 비디오 인디케이터 배지 및 마우스 호버 시 실시간 프리뷰 자동 재생 지원
  - 호버 시 은은한 반투명 그라디언트 오버레이로 타이틀 및 좋아요 투표수(`♥ N`) 노출
  - 카드 클릭 시 기존의 `openDetailModal(item.id)` 상세 모달과 즉시 연동 (상세 보기, 고화질 영상 재생, 좋아요 투표, 수정/삭제 가능)
- [x] **크기 및 개수 규칙**:
  - 카드 최소 크기: **90×90px** 보장
  - 한 줄(가로 또는 세로 축) 기준 **최대 10개** 나열 (`maxCols <= 10`, `maxRows <= 10`)
  - 폭 1024px 기준: 10개를 나열할 때 패딩 및 간격을 고려하여 여백 없이 꽉 찬 그리드 구성
- [x] **동적 반응형 배치 알고리즘**:
  - 뷰포트의 폭과 높이 비율(`W / H`) 및 항목 개수 `N`에 따라 긴 축을 기준으로 최대 10개를 배치하여 공간을 꽉 채움:
    - **폭이 길 때 (가로형, W > H)**: 긴 쪽인 가로(열)를 기준으로 최대 10개 나열 (예: 36개인 경우 **10×4 배열**)
    - **높이가 길 때 (세로형, H > W)**: 긴 쪽인 세로(행)를 기준으로 최대 10개 나열 (예: 36개인 경우 **4×10 배열**)
    - **폭과 높이가 비슷할 때 (정방형, W ≈ H)**: 정방형에 가까운 균형 배치 (예: 36개인 경우 **6×6 배열**)
- [x] **화면 최대 수용 한도 및 동적 이미지 크기 조절**:
  - 한 화면(페이지)에 노출되는 최대 항목 수를 **10×6 (가로형 최대 60개)** 또는 **6×10 (세로형 최대 60개)** 수준으로 최적화
  - 가용 폭과 높이에 맞춰 카드가 90px 이상의 최적 크기(예: 112px, 140px 등)로 화면을 가장 꽉 차게 채우도록 동적 크기 계산
  - 60개 초과 시 또는 화면 크기 초과 시 자연스럽게 세로 스크롤 허용
- [x] **실시간 반응형 리사이즈 및 투표 동기화**:
  - 브라우저 창 크기 조절 시(`resize`) 디바운스 최적화로 버벅임 없이 즉시 재배치
  - 모아보기 모드에서 투표 발생 시 실시간으로 데이터 및 하트 배지 동기화
  - `ESC` 키로 간편한 모달 닫기 지원

## 2. 세부 구현 아키텍처

### 1) 템플릿 변경 (`app/templates/event/detail.html`)
1. **히어로 영역 CTA 버튼**:
   - `openAggregateModal()` 호출 버튼 추가 (`border border-slate-700/50 hover:border-brand-500/50`)
2. **갤러리 섹션 헤더**:
   - `btn-view-card`, `btn-view-aggregate` 토글 탭 및 `전체화면 모아보기` 버튼 추가
3. **인라인 모아보기 뷰 (`#inline-aggregate-container`)**:
   - 갤러리 섹션 내에서 일반 카드뷰 대신 즉시 모아보기 그리드로 전환 가능
4. **전체화면 모아보기 모달 (`#aggregate-modal`)**:
   - 창 전체(`100vw`, `100vh`)의 가용 영역을 꽉 채우는 다크 글래스모피즘 뷰포트
   - 상단 헤더: 전체 개수 배지, 현재 계산된 그리드 사양 배지(예: `10 × 4 (가로 꽉 찬 배열) · 112×112px`), 최신순/인기순 실시간 정렬 버튼, 브라우저 전체화면 토글 버튼, 닫기 버튼
   - z-index 계층 구조: 모아보기 모달(`z-50`), 상세 모달(`z-[60]`)로 계층화하여 모아보기에서 카드를 클릭해 상세 모달을 보고 닫아도 모아보기 상태가 그대로 유지됨

### 2) 동적 그리드 계산 엔진 (`calculateAggregateGrid`)
```javascript
function calculateAggregateGrid(itemCount, availWidth, availHeight) {
    const minSize = 90;
    const gap = 8;
    const maxLine = 10;
    ...
}
```
- 화면 종횡비(`aspect = W / H`)에 따른 분기:
  - `aspect >= 1.25`: 폭 기준 최대 10열 나열 (`targetCols = min(10, physMaxCols)`, `targetRows = ceil(N / targetCols)`) -> N=36일 때 10×4
  - `aspect <= 0.8`: 높이 기준 최대 10행 나열 (`targetRows = min(10, physMaxRows)`, `targetCols = ceil(N / targetRows)`) -> N=36일 때 4×10
  - `0.8 < aspect < 1.25`: 정방형 분할 (`c = min(ceil(sqrt(N)), 10)`) -> N=36일 때 6×6
- 카드 크기는 `cardSize = min(sizeW, sizeH)`로 정사각형을 유지하며 가용 영역을 가득 채움
